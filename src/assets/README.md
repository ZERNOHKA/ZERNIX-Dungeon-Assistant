# Арт ZERNIX — единая папка

**Используйте только эту папку** для картинок, которые нужны приложению.

| Файл / папка | Назначение |
|--------------|------------|
| `logo-dragon.png` | Логотип в левом сайдбаре |
| `publicd20_dice.png` | Кубик d20 внизу сайдбара |
| `backgrounds/<раздел>/` | Фоны по разделам (см. `backgrounds/README.md`) |

Подключение — через `src/lib/zernixArt.ts` (логотип, d20) и `src/lib/sectionBackgrounds.ts` (фоны).

Не дублируйте рабочие изображения в `public/` или в корне проекта.
