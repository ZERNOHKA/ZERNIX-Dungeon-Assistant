# Section Backgrounds

Кладите PNG/JPG/WEBP **только сюда** — `src/assets/backgrounds/<раздел>/`.

Не дублируйте в `public/` или корневой `assets/` — приложение их не читает.

## Папки разделов

- `home/` — главный экран
- `loot/` — генератор лута
- `npc/` — создание NPC
- `prep/` — подготовка сессии
- `conditions/` — энциклопедия состояний
- `table/` — режим «За столом»
- `history/` — журнал
- `favorites/` — избранное
- `settings/` — настройки

## Как добавить фоны

1. Положите PNG/JPG/WEBP в нужную папку (любое имя файла).
2. Vite подхватит файл через `import.meta.glob` (обычно достаточно сохранить файл).
3. Если в папке несколько изображений — смена каждые ~14 с с crossfade.

## Форматы

`.png`, `.jpg`, `.jpeg`, `.webp`

## Резервный фон

Если папка пуста — показывается `public/zernix-hero-bg.png` (атмосферный слой без дракона раздела).
